# Factorial Program in Python

## Overview
This project contains a beginner-friendly Python program to calculate the factorial of a non-negative integer entered by the user.

## How It Works
- Takes an integer as input from the user.
- Checks whether the number is negative.
- If the number is non-negative, calculates its factorial using a `for` loop.
- Displays the calculated factorial.
- Prints a message if the input number is negative.

## Example
**Input:**
```text
Enter a non-negative integer: 5
```

**Output:**
```text
Factorial = 120
```

## How to Run
1. Make sure Python is installed on your computer.
2. Download `factorial.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run the command:

```bash
python factorial.py
```

## Learning Objective
To understand user input, conditional statements, loops, and basic arithmetic operations in Python.
